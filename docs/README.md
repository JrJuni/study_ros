# ROS와 Isaac Sim 학습자료 안내

이 폴더는 수업에서 실제로 다룬 내용을 날짜별 교재로 정리하는 공간이다.
각 문서는 혼자 다시 읽고 실습해도 이해할 수 있도록 작성한다.

| 순서 | 카테고리 | 배우는 내용 |

나누어 기록한다.

## 파일 이름 규칙

- 형식: `lesson_YYMMDD.md`
- 날짜 기준: Asia/Seoul
- 예시: 2026년 8월 2일은 `lesson_260802.md`
- 같은 날짜에는 기존 파일을 갱신하고, 날짜가 바뀌면 새 파일을 만든다.
- `lesson_260000.md`처럼 실제로 존재하지 않는 날짜는 사용하지 않는다.

## 네 단계 문서 구조

각 학습 주제는 아래 네 부분을 정확한 순서로 갖는다.

```markdown
## 1. [카테고리] 학습할 내용

### 주제

이번에 배우는 내용을 한 문장으로 적는다.

### 학습 목표

- 수업 후 설명하거나 수행할 수 있어야 하는 행동을 적는다.

### 내용 설명

용어의 뜻, 필요한 이유, 작동 원리와 주의점을 쉬운 말로 설명한다.

### 예제 또는 실습

실행 위치, 명령 또는 코드, 예상 결과와 확인 방법을 적는다.
실행 전이면 `실습 상태: 예정`, 실행했다면 `실습 상태: 완료`라고 표시한다.
```

추가 원칙:

- 학습 목표는 `이해한다`보다 `차이를 말할 수 있다`처럼 확인 가능하게 쓴다.
- 예제 코드는 복사해 실행할 수 있어야 하며 초보자용 주석을 포함한다.
- 예상 출력과 실제 실행 결과를 구분한다.
- 오류 메시지, 원인과 해결 과정도 학습 내용으로 남긴다.
- 바뀔 수 있는 제품 정보는 공식 문서를 우선하고 출처를 남긴다.
- 마지막에는 완료한 내용과 아직 하지 않은 내용을 구분한다.
