# 날짜별 ROS 학습자료 템플릿

아래 구조를 사용하고 대괄호 부분을 실제 내용으로 바꾼다. 큰 카테고리마다 장을
만들고, 한 장 안의 주제가 여러 개면 `0-1`, `0-2`처럼 절 번호를 늘린다.

```markdown
# YYYY-MM-DD 학습 기록 — [오늘 수업 제목]

- 학습자 수준: 로봇 입문
- 오늘의 상태: [실제로 완료한 범위]
- 아직 하지 않은 것: [예정된 내용]

## 0. 학습 안내

### 이 장의 학습 목표

- [전체 과정의 최종 목표를 설명할 수 있다.]
- [전체 학습 경로를 설명할 수 있다.]

### 0-1. [세부 주제 이름]

#### 주제

[무엇을 배우는지 한두 문장]

#### 내용 설명

[새 용어, 필요한 이유, 작동 원리와 주의점]

#### 예제 또는 실습

실습 상태: [예정/완료]

코드나 명령에는 초보자용 주석을 포함한다.

예상 또는 실제 결과: [결과]

성공 확인: [학생이 직접 확인할 방법]

## 1. [첫 번째 실제 학습 카테고리]

### 이 장의 학습 목표

- [이 장을 마친 뒤 확인할 수 있는 행동]

### 1-1. [세부 주제 이름]

#### 주제

[세부 주제]

#### 내용 설명

[설명]

#### 예제 또는 실습

실습 상태: [예정/완료]

## 오늘의 진행 상태

### 완료

- [실제로 끝낸 내용]

### 다음에 할 일

- [다음 학습 또는 실습]

## 참고 자료

- [공식 문서 제목](공식 문서 URL) — 확인일: YYYY-MM-DD
```
